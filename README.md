# dumbmahjong

Mahjong Solitaire for iPhone and iPad, without the nonsense. No ads, no in-app
purchases, no accounts, no network access, and no fireworks every time you match
a pair. Just pleasant tiles, deals that are always solvable, and unlimited undo.

See [DESIGN.md](DESIGN.md) for the design and the
[issues](https://github.com/thepaul/dumbmahjong/issues) for the work plan.

## Layout

| Path | What |
|---|---|
| `App/` | SwiftUI app target (an Xcode synchronized folder: new files are picked up automatically) |
| `MahjongCore/` | Swift package with all game logic. No UIKit/SwiftUI. Bundled layouts (JSON) live in `Sources/MahjongCore/Layouts/`. |
| `App/Tilesets.xcassets/` | Tile face images, generated by `tools/build_tileset.py` |
| `tools/tilesets/` | Tileset sources: SVGs, manifest, credits |
| `Config/` | Build settings; your signing team goes in the git-ignored `Local.xcconfig` |

## Building

Requires Xcode 16 or later. Deployment target is iOS 18.

To rebuild tile images after changing a tileset's sources (needs `brew install
librsvg imagemagick`):

```sh
python3 -I tools/build_tileset.py tools/tilesets/commons
python3 -I tools/build_icon.py      # app icon, from the tileset's red dragon
```

```sh
# Core logic tests (no simulator needed). Release mode runs them in seconds
# instead of minutes; -enable-testing is needed for a release test build.
swift test --package-path MahjongCore -c release -Xswiftc -enable-testing

# The same in debug, which is slow but better for tracking down a failure
swift test --package-path MahjongCore

# App build
xcodebuild -project DumbMahjong.xcodeproj -scheme DumbMahjong \
  -destination 'generic/platform=iOS Simulator' build
```

### Running on your own device

Signing uses your Apple Developer team, which stays out of the repo:

```sh
cp Config/Local.xcconfig.example Config/Local.xcconfig
# edit it: DEVELOPMENT_TEAM = <your team ID>
```

Then build and run from Xcode, or from the command line:

```sh
xcodebuild -project DumbMahjong.xcodeproj -scheme DumbMahjong -configuration Release \
  -destination 'id=<device UDID>' -derivedDataPath build -allowProvisioningUpdates build
xcrun devicectl device install app --device <device UDID> \
  build/Build/Products/Release-iphoneos/DumbMahjong.app
```

`xcrun devicectl list devices` shows connected devices and their UDIDs.
